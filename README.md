# Desafio Full Cycle — DDD: Modelagem Tática e Patterns

Implementação dos desafios do curso DDD: Modelagem Tática e Patterns.

## Requisitos

- **Node.js** >= 16 (testado com Node 22)
- **npm** >= 8

Não é necessário instalar banco: o SQLite roda em memória (`storage: ":memory:"`).

## Instalação

```bash
npm install
```

## Comandos

| Comando | O que faz |
|---|---|
| `npm test` | Roda o type-check (`tsc --noEmit`) e em seguida toda a suíte de testes (Jest + SWC). |


### Rodar os testes

```bash
npm test
```
